# Application tracker

## How to read this

`stage`: applied → screening → interview → offer → closed
`last touch`: last real action — applied, emailed, called, follow-up sent
`next`: the specific next action + when it's due. Never leave it blank. A row with no `next` is a dead row.

## Stale flags
`!` = no touch in 7 days. `!!` = no touch in 14 days. Flagged rows get chased, not guilt-tripped.
